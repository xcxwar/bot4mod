نسخه آماده GitHub + Render برای اجرای هر چهار ربات در یک Web Service رایگان

۱) تمام محتویات این پوشه را در ریشه یک repository در GitHub آپلود و Commit کن.
۲) در Render گزینه New → Blueprint را انتخاب کن و همان repository را وصل کن. فایل render.yaml یک Web Service می‌سازد.
۳) هنگام ساخت، متغیرهای محیطی خواسته‌شده را وارد کن. توکن‌ها و API keyها عمداً از کد حذف شده‌اند و نباید در GitHub نوشته شوند.

متغیرها:
- BOT_TOKEN: توکن ربات دانلودر
- GPT_BOT_TOKEN: توکن ربات GPT
- BALE_TOKEN: توکن ربات گرشا
- BALE_BOT_TOKEN: توکن ربات خبر
- GAPGPT_API_KEY: کلید API گرشا
- OPENAI_API_KEY: کلید سرویس اصلی GPT (در کد از endpoint گپ‌جی‌پی‌تی استفاده شده)
- GEMINI_API_KEY: کلید پروفایل Gemini
- OWEN_API_KEY: کلید پروفایل OWEN
- GROQ_API_KEY: کلید Groq

مهم:
- هر ربات باید توکن معتبر و یکتای خودش را داشته باشد. API keyهای اختیاری را اگر استفاده نمی‌کنی خالی بگذار.
- فایل render.yaml فقط یک Web Service ایجاد می‌کند و هر چهار اسکریپت را زیر نظر یک supervisor اجرا می‌کند؛ مسیر /healthz برای بررسی سلامت وب‌سرویس است.
- پلن رایگان Render ممکن است بعد از بی‌کاری وب‌سرویس را بخواباند؛ در نتیجه پاسخ‌دهی ربات‌های long-polling می‌تواند وقفه داشته باشد. این بسته تضمین uptime دائمی نمی‌دهد.
- کلیدها/توکن‌هایی که قبلاً داخل فایل‌ها بوده‌اند افشاشده محسوب می‌شوند؛ آن‌ها را باطل کن و کلید/توکن جدید در Render وارد کن.
